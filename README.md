# 🏛️ نظام الرقابة الإدارية، متابعة المهام، وقرارات مجلس الإدارة
> منصة تنفيذية متكاملة لإدارة التدرج النظامي للمساءلات والإنذارات، متابعة إنجاز المهام، ورصد قرارات مجلس الإدارة ونسب تحقيقها.

---

## 📌 نبذة عن النظام
يهدف هذا النظام إلى توفير حل عملي ومباشر للمدير التنفيذي وإدارة الموارد البشرية لضبط العمليات اليومية وتوثيق الالتزام المهني بدقة، إضافة إلى أرشفة منجزات الموظفين ومتابعة تكليفات مجلس الإدارة واستخراج تقارير رسمية جاهزة للطباعة.

---

## 🚀 المميزات الرئيسية

### 1. وحدة المساءلات والإنذارات الموثقة
* **التدرج الآلي للإجراءات الإدارية:**
  * إنذار شفوي (أولاً مع التوثيق الكامل).
  * مساءلة إدارية.
  * إنذار كتابي أول.
  * إنذار كتابي نهائي.
* **رصد زمني فوري:** تسجيل تلقائي وتوثيق لليوم، التاريخ، وساعة حدوث الواقعة.
* **تغطية شاملة لأنواع المخالفات:** (تأخير صباحي، غياب بدون عذر، خروج أثناء الدوام بدون إذن، خروج مبكر بدون إذن، مخالفات ضوابط الإجازات).
* **إصدار الخطابات فورياً:** استخراج نماذج خطابات إدارية رسمية معتمدة لكل إجراء بضغطة زر.

### 2. وحدة التكليفات والمهام التنفيذية
* تمكين المدير التنفيذي من إسناد المهام بأسماء الموظفين وتحديد مستهدفاتها.
* نافذة للموظف لتقديم تقارير الإنجاز وإرفاق روابط المستندات والإثباتات الرسمية.
* إمكانية اعتماد المهمة وتغيير حالتها إلى "تم الإنجاز"، وتنتقل تلقائياً ومباشرة إلى السجل التراكمي لمنجزات الموظف.

### 3. وحدة متابعة قرارات مجلس الإدارة
* توثيق قرارات الجلسات بأرقامها ونصوصها الرسمية.
* تكليف الموظف المعني بتنفيذ القرار ومتابعة مراحل التنفيذ.
* احتساب نسبة الإنجاز العامة للقرارات آلياً ومباشرة.
* إصدار تقرير رسمي للمجلس يوضح ما تم إنجازه وما لم يتم، ملائم لتقديمه في اجتماعات المجلس القادمة.

### 4. سجل الأداء التراكمي والتقارير
* ملف إنجاز والتزام منفصل لكل موظف.
* عداد دقيق يرصد عدد الإنذارات الشفوية المنفصلة ومجموع الإنذارات الخطية.
* أرشيف بكافة المنجزات المعتمدة وروابط إثباتاتها.
* جاهزية كاملة للطباعة بدون أزرار أو قوائم تحكم (`Print-friendly`).

---

## 🛠️ التقنيات المستخدمة
* **HTML5 / CSS3 / JavaScript (ES6):** لبناء واجهة سريعة، متجاوبة مع الهواتف والحواسب، وتعمل محلياً أو سحابياً بالكامل.
* **Bootstrap 5 (RTL):** تصميم مخصص يدعم اللغة العربية والاتجاه من اليمين لليسار.
* **GitHub Pages:** لتشغيل ونشر النظام كرابط موقع مجاني ودائم بدون تكاليف استضافة أو خوادم.
